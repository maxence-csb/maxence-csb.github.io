Cours PHP pour Débutants

Apprenez les bases du PHP pas à pas

1. Types de données, variables et portées

  • string : texte, ex. "Bonjour"
  • int : nombre entier, ex. 25
  • float : nombre à virgule, ex. 3.14
  • bool : vrai/faux, ex. true ou false
  • array : tableau, ex. [1,2,3]
  • null : valeur vide
$nom = "Alice";
$age = 25;
$estEtudiant = true;

2. Structures alternatives

$age = 18;
if ($age >= 18) { echo "Majeur"; }
elseif ($age >= 13) { echo "Adolescent"; }
else { echo "Enfant"; }

$couleur = "rouge";
switch ($couleur) {
    case "rouge": echo "Stop !"; break;
    case "vert": echo "Go !"; break;
    default: echo "Inconnu";
}

4. Fonctions

function direBonjour($nom){ return "Bonjour, $nom !"; }
echo direBonjour("Alice");

function afficherMessage($msg){ echo $msg; }
afficherMessage("Salut !");

function saluer($nom="Inconnu"){ echo "Bonjour, $nom !"; }
saluer();
