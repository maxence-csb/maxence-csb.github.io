Cours PHP pour Débutants

Apprenez les bases du PHP pas à pas, avec des exemples pratiques.

1. Types de données, variables et portées

En PHP, les variables permettent de stocker des données. Chaque variable a un type : string, int, float, bool, array ou null.

  • string : chaîne de caractères. Exemple : "Bonjour"
  • int : entier. Exemple : 25
  • float : nombre à virgule. Exemple : 3.14
  • bool : booléen vrai/faux. Exemple : true ou false
  • array : tableau contenant plusieurs valeurs. Exemple : [1,2,3]
  • null : variable vide ou non définie

Exemple :

$nom = "Alice";  // string
$age = 25;             // int
$estEtudiant = true;   // bool

Note : Les variables commencent toujours par $ et sont sensibles à la casse.

2. Structures conditionnelles

Les conditions permettent de prendre des décisions dans le code.

if / elseif / else :

$age = 18;
if ($age >= 18) {
    echo "Majeur";
} elseif ($age >= 13) {
    echo "Adolescent";
} else {
    echo "Enfant";
}

switch :

$couleur = "rouge";
switch ($couleur) {
    case "rouge": echo "Stop !"; break;
    case "vert": echo "Go !"; break;
    default: echo "Inconnu";
}

Astuce : Toujours inclure break; dans un switch pour éviter l’exécution des cas suivants.

3. Boucles

Les boucles permettent de répéter du code plusieurs fois.

for : quand on connaît le nombre d’itérations

for ($i=1; $i<=5; $i++) {
    echo "Compteur $i
";
}

while : répète tant qu’une condition est vraie

$i=1;
while ($i<=3) {
    echo "Itération $i
";
    $i++;
}

foreach : pour parcourir un tableau

$fruits=["pomme","banane","orange"];
foreach($fruits as $fruit){
    echo $fruit."
";
}

4. Fonctions

Les fonctions permettent de réutiliser du code et de structurer votre programme.

function direBonjour($nom){
    return "Bonjour, $nom !";
}
echo direBonjour("Alice");
function afficherMessage($msg){
    echo $msg;
}
afficherMessage("Salut !");
function saluer($nom="Inconnu"){
    echo "Bonjour, $nom !";
}
saluer(); // Affiche "Bonjour, Inconnu !"

Astuce : Les paramètres peuvent avoir des valeurs par défaut.

5. Tableaux

Les tableaux stockent plusieurs valeurs dans une seule variable.

$fruits=["pomme","banane","orange"];
echo $fruits[0]; // pomme
$personne=["nom"=>"Alice","age"=>25];
echo $personne["nom"]; // Alice
foreach($personne as $cle=>$valeur){
    echo "$cle : $valeur
";
}

Astuce : Les tableaux associatifs utilisent des clés pour identifier les valeurs.

6. Include / Require

Ces instructions permettent d’inclure un fichier dans un autre pour réutiliser du code.

include "header.php";      // inclut le fichier, continue même si erreur
require_once "config.php"; // inclut le fichier une seule fois, stop si erreur

7. Transmettre des données

Il existe plusieurs façons de transmettre des informations :

GET : via l’URL

<a href="page2.php?nom=Alice&age=25">Envoyer</a>
$nom = $_GET['nom'];
$age = $_GET['age'];

POST : via un formulaire

<form method="post" action="traitement.php">
<input type="text" name="nom">
<input type="submit">
</form>
$nom = $_POST['nom'];

SESSION : conserver des informations entre plusieurs pages

session_start();
$_SESSION['nom'] = "Alice";

Astuce : Toujours faire session_start() au début de la page avant de manipuler les sessions.
